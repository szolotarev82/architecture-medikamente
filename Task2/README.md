# Описание новых компонентов архитектуры и их задач в контексте Privacy by Design (PbD)

* **Единый веб-портал компании:** Универсальный веб-интерфейс, через который работают все пользователи системы, за исключением бухгалтеров, кладовщиков и бизнес аналитиков. Пациенты используют его как Личный кабинет для самостоятельной регистрации по Email и записи на прием. Сотрудники ресепшена авторизуются в нем через доменные учетные записи для контроля расписания и фиксации напоминаний. Вся работа происходит в рамках единого фронтенда, разделенного правами доступа.

* **Локальный API Gateway и IAM:** Входной шлюз безопасности, скрытый за Веб-порталом. Проверяет пароли персонала в Active Directory (LDAPS) и регистрирует пациентов по Email. Выдает краткосрочные JWT-токены. Обеспечивает централизованную авторизацию и аутентификацию, защищая внутренний контур от внешних несанкционированных вызовов.

* **Локальный шлюз безопасности данных:** Специализированный прокси-сервер ИБ, размещенный между API Gateway и хранилищами. На лету выполняет обфускацию, анонимизацию и валидацию прав доступа на основе тегов данных. Реализует конфиденциальность по умолчанию, автоматически маскируя телефоны (`+7(999)***-45-67`) для ресепшена и полностью блокируя им доступ к медицинским картам.

* **Сервер KMS (HashiCorp Vault):** Автономная служба хранения и выдачи ключей. Обеспечивает сквозную безопасность. Ключи отделены от баз данных и файлов. PostgreSQL и MinIO запрашивают их по API только в оперативную память при старте, исключая доступ для системных администраторов инфраструктуры.

* **Сервер хранилища MinIO (S3):** Объектное хранилище для JPG/PDF сканов, договоров и анализов. Защищает данные на всем жизненном цикле, автоматически шифруя файлы на дисках (SSE-KMS). Прямой доступ сети закрыт.

* **Оркестратор ETL (Apache Airflow):** Платформа для запуска ночных Python-скриптов для наполнения базы аналитики.

* **Сервер аналитики ClickHouse:** Колоночная СУБД для отчетов P&L/ABC в Jupyter, изолированная от имен пациентов. Реализует принцип полной функциональности, позволяя вести BI без риска утечки ПДн.

* **Сервис неизменяемого аудита (Immutable Audit Logger):** Модуль логирования действий пользователей на отдельном физическом сервере. Гарантирует открытость и прозрачность. Пишет логи по протоколу Syslog по защищенному mTLS-каналу в режиме Append-Only (только добавление). Записи защищены от удаления и модификации ИТ-персоналом или разработчиками.
