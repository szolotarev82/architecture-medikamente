# Реестр классификации и инструментов защиты данных

| Данные | В чём необходимость защиты | Инструменты защиты |
| :--- | :--- | :--- |
| **1. Паспортные данные и СНИЛС** | Критичные личные данные. Могут использоваться мошенниками для кражи личности или шантажа. | • **Шифрование дисков (PostgreSQL TDE):** Защищает файлы базы и бэкапы от копирования.<br>• **Маскирование на экране:** Полное скрытие разрядов паспорта для ресепшена в списках (формат `45** ***456`). |
| **2. Контакты пациентов**<br>(Телефоны, Email) | Клиентская база клиники. Риск массовой кражи сотрудниками для продажи конкурентам или спам-рассылок. | • **Динамическая обфускация:** Шлюз на лету скрывает цифры звездочками (`+7(999)***-45-67`). Номер открывается только внутри карточки звонка.<br>• **Шифрование сети:** Запрет HTTP, использование TLS 1.3. |
| **3. Диагнозы и медкарты** | Врачебная тайна. Риск любопытства персонала и утечки историй болезней, что ведет к судам и потере репутации. | • **Разделение баз данных:** В базе медкарт нет имен, только скрытый номер `patient_uuid`. ФИО хранятся отдельно.<br>• **Шифрование колонок (pgcrypto):** Сисадмин базы видит вместо текста диагнозов пустые бинарные байты. |
| **4. Результаты анализов** | Медицинские бланки (PDF/JPG) от Лаборатории, содержащие врачебную тайну. | • **Изоляция в MinIO S3:** Файлы лежат в закрытом хранилище с шифрованием на дисках (SSE-KMS).<br>• **Временные ссылки:** Врач видит файл по ссылке со сроком жизни 10 минут. Массово скачать файлы нельзя. |
| **5. Бумажные согласия**<br>(Сканы документов) | Юридические документы с подписями пациентов. Риск копирования сканов паспортов админами с общего диска. | • **Отказ от папок Windows:** Перенос всех сканов в MinIO S3 под защиту локального сервера ключей **KMS (HashiCorp Vault)**.<br>• **mTLS-авторизация:** Доступ к файлам имеют только проверенные серверы. |
| **6. Пароли сотрудников** | Доступ ко всей системе клиники. Риск перехвата паролей ресепшена в локальной сети или их подбора. | • **Интеграция с Active Directory:** Пароли не хранятся в МИС. Проверка идет по шифрованному каналу **LDAPS (порт 636)**.<br>• **Защита сессий:** Выдача краткосрочных JWT-токенов. |
| **7. Пароли пациентов** | Доступ к Личному кабинету на сайте. Риск взлома аккаунтов перебором или кражи паролей при взломе СУБД. | • **Криптографическое хэширование:** Пароли шифруются функциями с солью (**Argon2id** / **bcrypt**).<br>• **Защита API от подмены ID (BOLA):** Пациент видит только свои данные: `user.id == data.patient_id`. |
| **8. Базы 1С и финансы**<br>(Счета, проводки, выручка) | Коммерческая тайна бизнеса. Риск изменения логов оплат инсайдерами и кражи финансовых отчетов конкурентами. | • **Миграция на PostgreSQL:** Отказ от файлового режима 1С. Базы переносятся в PostgreSQL с шифрованием дисков (TDE).<br>• **Разделение сети:** Выделение трафика 1С в закрытый контур VLAN. |
| **9. Расписание врачей** | Операционные данные клиники. Риск выкачивания сетки конкурентами или умышленной блокировки слотов ботами. | • **Rate Limiting:** Ограничение частоты запросов на шлюзе для блокировки роботов.<br>• **Права (RBAC):** Пациент видит только «Свободно/Занято», ресепшен — имя клиента. |
| **10. Отчеты аналитика**<br>(Данные в ClickHouse) | Финансовые метрики эффективности клиники (P&L, ABC-анализ). Риск кражи коммерческой аналитики. | • **Локальный ETL (Apache Airflow):** Пайплайн по ночам переносит данные, полностью стирая ФИО. Аналитик видит только цифры.<br>• **k-анонимизация:** Выборки менее 5 человек размываются СУБД. |
| **11. Журнал ИБ-аудита** | Единственный след для расследования инцидентов. Риск стирания логов хакером или админом для скрытия кражи. | • **WORM-хранилище:** Выделенный Сервер аудита работает в режиме *Append-Only* (только добавление). Удаление строк запрещено ОС.<br>• **Syslog over TLS:** Асинхронная отправка JSON-логов по mTLS-каналам. |
| **12. Ключи шифрования** | Наивысшая критичность. Компрометация ключа обесценивает всю защиту клиники. | **Централизация в HashiCorp Vault:** Полный запрет на хранение ключей в файлах конфигурации. Ключи выдаются базам только в память при старте.<br>• **Платы доверенной загрузки (Соболь):** Защита ОС сервера KMS на уровне железа. |
